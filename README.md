# Project-Resume-Classification

The document classification solution should significantly reduce the manual human effort in the HRM. It should achieve a higher level of accuracy and automation with minimal human intervention.

Resume classification is the task that automatically categorizes resumes or CVs into predefined domain categories or classes based on their content. This task is essential for the job recruitment process, particularly when organizations receive a large number of applications for various positions.

NLP technology allows recruiters to electronically gather, store, and organize large quantities of resumes. Once acquired, the resume data can be easily searched through and analyzed.

The NLP resume classification pipeline involves steps such as data acquisition, data preprocessing, text tokenization, stop word removal, text normalization, feature extraction, model training, model evaluation, model deployment, and iterative improvement.
